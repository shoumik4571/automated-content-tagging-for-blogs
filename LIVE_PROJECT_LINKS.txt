2. QUICK-START COMMANDS (REPRODUCE OR RUN LOCALLY IN <60 SECONDS)
--------------------------------------------------------------------------------
A) Reproduce Data Curation, Deduplication & Multi-Model Training Pipeline:
   cd Source_Code
   pip install -r requirements.txt
   python src/prepare_data.py
   python src/train_and_evaluate.py

B) Start the FastAPI Backend + Talverin Next.js 15 UI Studio:
   python src/api_server.py
   cd talverin-ui && npm install && npm run dev
   --> Open http://localhost:3000

C) Or Launch the Single-Command Streamlit Editorial Workbench:
   streamlit run app.py
   --> Open http://localhost:8501
